# 🧮 System Product Inventory

**System Product Inventory** — это настольное приложение на **WPF (C#)** с использованием **Entity Framework**, предназначенное для управления товарами, категориями и статистикой.  
Простое, интуитивное и наглядное решение для учёта продукции и анализа её стоимости.

---

## ⚙️ Основные функции

### 🗂 Управление товарами
- Просмотр всех товаров в базе данных  
- Добавление нового товара  
- Редактирование существующих записей  
- Удаление ненужных товаров

### 🧩 Управление категориями
- Просмотр списка категорий  
- Выбор категории при создании или изменении товара  
- Автоматическое отображение названия категории вместо её `ID`

### 📊 Статистика
- Отображение количества товаров и их общей стоимости по категориям  
- Расчёт:
  - **Общей суммы всех товаров**
  - **Средней цены по категориям**
- Поиск категорий по названию
- Мгновенное обновление статистики после поиска
